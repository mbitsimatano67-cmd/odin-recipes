# Odin Recipes

This project is part of The Odin Project Foundations course.

I will build a basic recipe website using HTML. The website will contain
a main page with links to different recipe pages.

## Skills Demonstrated

By completing this project, I will demonstrate my ability to:

- Create and structure HTML documents
- Use headings, paragraphs, and lists
- Create links between webpages
- Add images to webpages
- Organize files and folders
- Use Git and GitHub
- Clone a repository using SSH
- Commit and push changes to GitHub
